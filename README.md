# ShellForge

ShellForge is a Unix-like shell developed as part of the Operating Systems and Systems Programming Project-Based Learning course.

## Features (Week 1)

- Interactive REPL loop
- Makefile-based build
- Git repository
- Linux development environment

## Project Structure

- `src/` - Source code
- `include/` - Header files
- `bin/` - Compiled executable
- `docs/` - Documentation
- `tests/` - Testing files
- `screenshots/` - Project screenshots

## Build

make

## Run

make run

## Week 1

The first version of ShellForge contains a simple interactive REPL loop that reads user input and displays it back to the user.

The `exit` command terminates the shell.
